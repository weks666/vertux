# Визуальный контракт Nexus Site

Режим семейства: `nexus-site` из `projects/vertux-design-system/tokens/design-systems.json`. Действующая реализация `assets/site.css`, локальные шрифты и брендовые ассеты — визуальный источник истины. Платформа: web; языки RU/EN.

Сохраняем near-black `#07070A`, графитовые поверхности, Manrope, ограниченный акцент Unbounded и фиолетовый `#7C5CFF`. Основной текст `#F5F3FB`, вторичный `#AAA6B5`, светлый фиолетовый `#C8BCFF`. Новая основная кнопка использует более тёмный фиолетовый для контраста белого текста. Числа цены табличные, основной текст 16–17 px, подписи 13–15 px. На мобильном скриншот доступен крупнее по ссылке.

Сигнатура существующего сайта — продуктовое окно Nexus. Оно сохраняется в разделе бизнеса. Invest показывает реальный снимок учебной сборки, без искусственного результата клиента. Заголовки с менее плотным трекингом, ясные группы и спокойная новая поверхность; без дополнительных декоративных сеток, анимаций, цифровых меток и повторяющихся карточек функций.

`assets/landing.css` применяется только к главной странице, чтобы локальная доработка не меняла страницы кабинета и защищённой выдачи. Единые вкладки и RU/EN остаются в `assets/site.js`. Нативные details, видимый focus, touch-target от 44 px у новых кнопок, reduced-motion и рабочий основной контент без JavaScript обязательны.

Учебный разбор использует одну поверхность с вкладками, объяснением слева и управляемым примером справа. На телефоне порядок — объяснение, управление, результат. Калькулятор срока использует native radio, ползунок — native range, сравнение и начало работы — details. Контроль, итог и пояснение находятся рядом; изменения итогов доступны через aria-live. Новый модуль `assets/landing-interactions.js` не содержит сетевого контура и не меняет учётную запись посетителя.
