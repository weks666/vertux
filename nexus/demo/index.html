Расчёт сделки

Сколько лотов укладывается в ваш допустимый убыток при заданной стоп-цене.

Стоп-цена — уровень, на котором вы планируете выйти с убытком. Калькулятор не выставляет стоп-заявку; фактический убыток может быть больше из-за изменения цены исполнения и комиссий.

Для акций указывайте цены в рублях, для фьючерсов — в пунктах. При покупке стоп ниже входа, при шорте — выше.

Пример для акции: при допустимом убытке 1 000 ₽, входе 100 ₽ и стопе 95 ₽ разница составляет 5 ₽ на акцию. Получится 200 акций, если хватает капитала; результат округляется вниз до целых лотов.

Введите капитал, цены входа и стопа, затем нажмите «Рассчитать количество лотов».

Подключение API Т‑Банк Инвестиции

Безопасный ввод токена только для чтения через системное хранилище Windows DPAPI.

Зачем окно Windows:Эта веб-страница не увидит введённые данные. Токен вводится в отдельном нативном окне «Invest Workspace» и шифруется Windows через DPAPI для текущего пользователя.

• Основной контур: ваш реальный портфель. Выпустите токен в приложении/сайте Т‑Банка: Профиль → Настройки → Токены T-Invest → Создать токен с галочкой «Только чтение».

• Песочница: виртуальный баланс для проверки работы API без реальных денег.

Синхронизируются только позиции, сделки и портфель в режиме чтения. Торговые операции через этот токен невозможны.

Отключить T‑Invest?

Сохранённое подключение будет удалено. Уже загруженные данные останутся в кабинете.

Для повторного подключения понадобится заново пройти защищённый ввод в отдельном окне Windows.
