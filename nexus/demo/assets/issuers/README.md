# Логотипы эмитентов

Общедоступные изображения Т‑Инвест, получены 17 сентября 2026. Используются для идентификации соответствующих бумаг. У неизвестного инструмента отображается значок его типа; чужой логотип ему не назначается.

Документированный источник: https://developer.tbank.ru/invest/services/instruments/faq_instruments
