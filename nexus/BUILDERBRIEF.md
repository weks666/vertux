# Задача лендинга Nexus

Посетитель должен сразу понять два направления: готовящийся стандартный Invest Workspace для личного портфеля и индивидуальные Workspace для компаний. Показать цену выбранного месячного плана 1 490 ₽ и предварительные длительные периоды, сохраняя честный статус запуска.

Путь: первый экран с двумя переходами → Invest с настоящим учебным интерфейсом → единый план по срокам → ответы о брокерах, AI и Windows → индивидуальный Workspace → существующие возможности платформы → контакты и доступ к Nexus.

Запрос пользователя — доработать действующий лендинг с помощью impeccable, сохранив характер Vertux. Используем scoped polish и расширяем содержимое; новую визуальную идентичность не создаём. Изменения основного сайта студии вне `nexus/` не входят в задачу.
