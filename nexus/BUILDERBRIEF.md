# Задача лендинга Nexus

Главный продукт — личный Invest; индивидуальные системы для бизнеса — дополнительное направление. Посетитель должен увидеть продукт, попробовать настоящий интерфейс на учебных данных, понять две основные задачи, сравнить сроки подписки и перейти к регистрации или входу.

Путь: видеоряд с открывающимся ноутбуком → Invest на всю сетку → два кратких иллюстрированных объяснения → безопасность → три срока и FAQ → интерактивное бизнес-демо → отдельное приглашение обсудить свою систему → кабинет и заключительный CTA. Длинные секции статистики, процессов, знаний и запросов условий не возвращаются. Отзывы, клиенты и спонсоры не выдумываются.

Окно Invest сохраняет размер при смене разделов и прокручивает содержимое внутри. Заголовок расположен сверху, две кнопки — снизу. Навигация и компоненты берутся из настоящего приложения; учебный адаптер заменяет внешние источники и недоступные системные действия. Бизнес-демо позволяет выбирать вкладку без принудительной прокрутки через промежуточные состояния.

Первый фон — настоящий пятисекундный MiniMax-ролик: фотореалистичный ноутбук открывается на чёрной сцене с линией рассвета. Затем идут исходные сцены с людьми. Прежняя перспективная замена экранов отменена по отзыву пользователя. Заголовок виден с первого кадра, отдельной заставки сайта нет. Reduced-motion и Save-Data оставляют постер.

Плавающая шапка, локальный Inter, отдельная страница безопасности и отдельный путь регистрации делают навигацию понятнее. Ориентиры подачи — Linear и getquin; их оформление и заявления не копируются.

«Начать» и сроки подписки ведут через register.html?plan=month|quarter|year в защищённый кабинет на экран регистрации. Сайт не принимает пароли и не имитирует оплату. Публичное скачивание зависит от готовности реального артефакта. Локальный preview соединён только с изолированным fixture-кабинетом. Объём этой доработки — проверяемый локальный кандидат; публичный выпуск сайта, сервера и Desktop требует отдельной подтверждённой готовности сквозного пути.
