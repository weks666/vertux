# История изменений Nexus и Invest

После каждого разрешённого выпуска публиковать запись на https://vertux.online/nexus/updates.html. Обновление установщика или registry без актуального журнала не завершает выпуск. Это прямое требование владельца от 21 сентября 2026 года; повторное разрешение на эту часть выпуска не требуется.

Источник записей — `releases.json`. `updates.html` содержит готовую статическую разметку: история доступна без дополнительных запросов и JavaScript. Генератор использует существующий переключатель RU/EN, не добавляет браузерных зависимостей.

## Порядок

1. Проверить фактическую публикацию и release evidence. Брать дату публикации, а не сборки. Добавить в начало JSON версию продукта, 2–4 изменения для пользователя на русском и английском и уникальный ID. Серверное исправление без номера приложения можно оформить отдельной записью с label.
2. Не включать планы, неподтверждённые функции, локальные кандидаты или личные данные. Выпущенный компонент Invest и публичный установщик Nexus — разные факты. Например, Invest 0.6.8 опубликован, но Nexus 0.6.42 оставался локальным; публичная выдача перешла с 0.6.41 на 0.6.43.
3. Передать генератору **проверенные версии выпуска**, полученные независимо из receipts/registry. Не подбирать аргументы под старый JSON. Из корня репозитория сайта выполнить:

```powershell
node nexus/scripts/release-history.mjs --write --nexus 0.6.43 --invest 0.6.9
node nexus/scripts/release-history.mjs --check --nexus 0.6.43 --invest 0.6.9
git diff --check
```

4. Проверить RU/EN, desktop/mobile, переход к скачиванию и отсутствие ошибок браузера. Публиковать только относящиеся к задаче пути `nexus/` через текущую ветку GitHub Pages; сохранить предыдущий commit для отката.
5. После успешной Pages-сборки выполнить проверку опубликованного HTML, JSON и версии доступного установщика:

```powershell
node nexus/scripts/release-history.mjs --check --live --nexus 0.6.43 --invest 0.6.9
```

6. Сохранить URL, commit Pages и результат `LIVE_CHANGELOG_VERIFIED` в evidence выпуска. Проверка журнала не заменяет полное скачивание установщика, подпись, backup/restore или приёмку приложения.

Скрипт отклоняет пропущенные переводы, пустые записи, повторяющиеся версии, неправильный порядок дат, старую сгенерированную страницу и расхождение с переданными версиями. Live-проверка выполняет только публичные GET-запросы, не использует сеансы и не пишет в production.
