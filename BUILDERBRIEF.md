# BUILDERBRIEF — СБОРКА (портфолио + продажа сайтов/виджетов)

<role>
Сеньор веб-дизайнер уровня топового агентства. Делаю портфолио, которое одновременно продаёт услугу.
</role>

<task>
Портфолио веб-специалиста, который продаёт КОНВЕРСИОННЫЕ САЙТЫ и ВИДЖЕТЫ (боты сбора заявок).
Двойная цель: (1) показать работы, (2) продать услугу — «я могу собрать тебе такое же».
Целевое действие: оставить заявку (форма + чат-виджет → демо webhook).
</task>

<context>
Это личное портфолио. Продукт = сайты + виджеты под ключ (вайбкодинг через AI, деплой на Vercel).
3 реальных работы (живые на Vercel):
- V/FORMA (фитнес-лендинг + квиз-виджет): https://vladimir-fitness-nine.vercel.app
- ЯДРО (ресторан + букинг-виджет): https://yadro-restaurant.vercel.app
- PULSE (SaaS, EN/RU, orbital-анимация + чат-виджет): https://pulse-saas-ivory.vercel.app
Работы показываем честно как концепты/демо (mono-тег «концепт»), но живые и кликабельные.

Уникальное предложение vs конкуренты (типа aion-agent): у них только виджеты и ноль кейсов.
У меня — и сайты, и виджеты, и живые примеры можно потрогать прямо на странице.
Фишка: 7-дневный триал виджета, квалификация лида (3-5 вопросов) → Telegram/CRM.
</context>

<design_direction>
Near-black studio, чисто + дорого + умеренная анимация (портфолио = всё видно, без перебора).
- bg #0A0A0C, surface #131318, surface-2 #1A1A22
- text #EDEDF0, muted #8A8A95
- accent #7C5CFF (электрик-индиго), accent-2 #B9A6FF (свет), glow от него
- hairline rgba(255,255,255,0.08)
Шрифты: Unbounded (display, 700-900, Cyrillic), Manrope (body/UI, Cyrillic), JetBrains Mono (метки).
БЕЗ тире (только дефис). Линейные иконки/SVG, не эмодзи. Mono-метки секций [01]..[NN].
Анимации (со вкусом): cursor spotlight + aurora-mesh + dot-grid в hero; counter-up; reveal-stagger;
magnetic CTA; hover-lift; marquee; живые iframe-превью работ; интерактивная демка виджета (вкладки).
</design_direction>

<structure>
nav → hero (оффер+CTA+stats) → marquee инструментов → услуги (Сайты/Виджеты/Под ключ) →
работы (3 живых iframe-кейса) → ИНТЕРАКТИВНАЯ ДЕМКА ВИДЖЕТА (вкладки: Запись/Квалификация/Поддержка) →
процесс (4 шага) → подход (анти-слоп, не шаблоны) → тарифы (3, с триалом) → FAQ → финальный CTA + форма → footer.
Свой чат-виджет внизу справа (dogfooding).
</structure>

<constraints>
- НЕ шаблон, НЕ перебор. Портфолио читается с первого взгляда.
- Работы — честно как концепты, но живые ссылки.
- Один файл index.html + styles.css + script.js. Vanilla, без сборки. Адаптив.
</constraints>

## Дополнение: интеграция Vertux Nexus

- Vertux Nexus показывается как отдельный продукт студии, а не как ещё одна услуга в пакете «сайт + виджет».
- На первом экране используется компактный product-signal `NEW / VERTUX NEXUS`: он заметен, но не конкурирует с основным оффером.
- В подвале остаётся постоянная карточка-ссылка на продукт.
- Ссылка ведёт на честную публичную витрину `https://weks666.github.io/vertux-develop/`; незапущенные функции не называются доступными.
- Визуальный язык наследует текущий Vertux: near-black, #7C5CFF, hairline, мягкое свечение, без тяжёлой новой анимации.
